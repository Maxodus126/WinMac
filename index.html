What you get

Everything you miss, nothing you don't.

A complete macOS-style shell layer that stays out of your way — fast, native and beautifully rendered.

🌊

Liquid Glass dock

Live window capture behind the glass, bent at the rim like a lens. Magnification follows your pointer with cosine falloff — no blurred wallpaper copy.

🪄

Genie minimize

Windows shrink into their dock icon with a custom 48-row scanline mesh rasterizer — anti-aliased, threaded, and flicker-free.

⌘

Alt+Tab, the macOS way

One icon per app, most-recent-first, frosted panel. Quick tap flips to the previous app. Esc cancels, Q quits, H minimizes.

🔍

Spotlight

Hit Alt+Space. A glass capsule grows into results as you type — apps first, then web search.

📊

Menu bar & widgets

Front app menus that send real shortcuts, battery, Wi-Fi, Control Center, a calendar, and four frosted desktop widgets.

🔋

Real battery numbers

Charge, wear, cycles and a live power breakdown: CPU via RAPL, NVIDIA GPU via NVML, and the rest — no admin needed.

🤖

AI usage at a glance

Claude Code & Codex token burn rate, limits and per-session detail in the menu bar — read from local logs, no telemetry by default.

🗂️

Apps window

macOS 26-style Launchpad replacement with live search, category chips and recents. Full-screen Launchpad still available.

⚡

Barely there

Real AppBars, game mode that sleeps the render loop (0.00% CPU), and redraws only when something actually moves.

Get started

Up and running in seconds.

Just download and run — or build from source if you prefer.

Download the executable

Grab winmac.exe from the latest release and run it. Windows 11 only.

Or build from source

Install Rust, switch to the GNU toolchain (no Visual Studio needed), then:

rustup default stable-x86_64-pc-windows-gnu
git clone https://github.com/Maxodus126/WinMac.git && cd WinMac
cargo build --release

Make it yours

All settings live in %APPDATA%\WinMac\config.json — or use the floating Settings window with live preview.
